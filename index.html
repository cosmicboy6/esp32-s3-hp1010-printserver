ESP32-S3 Print Server

Browser installer for the raw TCP-9100 → USB Printer Class bridge firmware.

Connect a blank ESP32-S3 board over USB, then press Install for your printer. The installer talks to the board directly through your browser (Web Serial) — nothing is uploaded anywhere.

PrinterUSB IDInstall
HP LaserJet 101003F0:0C17 Browser doesn't support Web Serial — use Chrome, Edge or Firefox on a desktop. Open this page over https:// to install.
DYMO LabelWriter 4500922:0020 Browser doesn't support Web Serial — use Chrome, Edge or Firefox on a desktop. Open this page over https:// to install.
Board requirement: ESP32-S3 with 16 MB flash + 8 MB octal PSRAM (e.g. ESP32-S3-DevKitC-1 N16R8). The prebuilt images are compiled for that exact target. For any other board, build from source instead.

After flashing the HP1010 image

  1. The device boots with no WiFi credentials, so it starts its fallback access point:
    SSID HP1010 Print Fallback  /  Password hp1010setup
  2. Join that network, then open http://192.168.4.1 (captive portal) and enter your real WiFi details.
  3. Find the device on your network (mDNS hp1010-printserver.local) and add it to Home Assistant using the API encryption key 9GXBCDmqW1uiTOdRJC60k8qvZ9W/yYW0jiE3xV/obGc=.
  4. Point a raw print queue at it:
    lpadmin -p HP1010 -E -v socket://hp1010-printserver.local:9100 -m <LJ1010 driver>

After flashing the DYMO 450 image

  1. The device boots with no WiFi credentials, so it starts its fallback access point:
    SSID DYMO Print Fallback  /  Password dymosetup
  2. Join that network, then open http://192.168.4.1 (captive portal) and enter your real WiFi details.
  3. Find the device on your network (mDNS dymo-labelwriter-450.local); it advertises itself as a DYMO LabelWriter 450 raw printer. Add it to Home Assistant using the API encryption key 9GXBCDmqW1uiTOdRJC60k8qvZ9W/yYW0jiE3xV/obGc=.
  4. Point the DYMO software (or CUPS) at the raw port:
    lpadmin -p DYMO450 -E -v socket://dymo-labelwriter-450.local:9100 -m <LW450 driver>
The prebuilt images intentionally contain no personal secrets (placeholder WiFi, publicly documented API key). To bake in your own credentials, build from source — see the README.
